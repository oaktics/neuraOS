# ブラウザのダウンロード

Webページのリンクやダウンロードボタンから保存すると、毎回macOSの保存ダイアログが開きます。名前と保存先を選択してください。同名の既存ファイルを置き換える場合はmacOSの確認が表示されます。

ブラウザの「ダウンロード」（下向き矢印）から、進捗・保存先・完了・キャンセル・失敗を確認できます。転送中はキャンセル、完了後は虫眼鏡からFinderで表示できます。ファイルを自動で開くことはありません。履歴はアプリの起動中のみ保持します。元のブラウザタブを閉じると、そのタブの未完了ダウンロードはキャンセルされます。

## 検証

`node scripts/native/chromium/download-smoke.mjs` はビルド済みアプリを隔離プロファイルで起動し、loopbackのリンククリック、保存bytes一致、転送中の進捗とキャンセル、通信切断、保存先選択の取消しを自動確認します。CIでは保存先選択だけをfixtureで注入し、実CEFのダウンロード・ファイルI/O・状態通知を使います。追加認証・権限操作は不要です。`NEURA_APP_OUTPUT`でパッケージを指定できます（既定`apps/macos/dist/neuraOS.app`）。スクリプトが一時コピーを作り、固有bundle ID・一時data directory・未使用endpointを設定して再署名するため、元パッケージは変更しません。workflowからビルド後に実行してください。

`NEURA_DOWNLOAD_SMOKE_MANUAL=1`を付けると実NSSavePanelで確認できます。complete/cancel/failedは「保存」、dismissは「キャンセル」を操作してください。名前と保存先はfixture側で事前設定します。ウィンドウ上部のダウンロードボタンは製品と同じ一覧UIです。

保存先とJSONレポートは毎回新規の`/tmp/neura-download-smoke-*`へ作成し、検証後も証跡として残します。実ユーザーファイルの上書きは行いません。

スモーク専用の揮発プロファイル設定がある場合だけ、Chromiumの`--use-mock-keychain`を使用します。実ユーザーのKeychainと通常プロファイルにはアクセスしません。通常起動でこのフラグが付かないことは`BrowserDownloadIsolationTests`で確認します。このfixtureは本番の暗号化、Webサービスへのログイン、認証情報の永続化を検証しません。
